# One Minute Outward

A one-minute zoom from a person in a park out to the edge of the observable
universe. Each step on the way (the city, the Earth, the Solar System, the
galaxy and beyond) is captioned with its real scale.

Watch it: https://milosarcade.com/one-minute-outward/

## Controls

| Key | Action |
|---|---|
| Space or K | Play / pause |
| Left / Right arrow | Back or forward 2 seconds |

Drag the timeline to scrub, and use the button on the right for fullscreen.
In browsers that support it, **Record video** saves the minute as a video file.

Add `#at30` to the address to open paused at 30 seconds (any number of seconds works).

A single HTML file, no build step. Served with GitHub Pages.
